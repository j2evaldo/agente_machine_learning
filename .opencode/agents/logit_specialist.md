## 2. THEORETICAL & MATHEMATICAL FOUNDATIONS

### 2.1 The Logit Link Function & Bernoulli Distribution
Logistic regression models binary target variables $Y_i \in \{0, 1\}$ generated by an underlying Bernoulli process where $P(Y_i = 1 | X_i) = p_i$.
To map the unbounded linear predictor $\eta_i = \mathbf{X}_i \boldsymbol{\beta} = \beta_0 + \sum_{j=1}^p \beta_j X_{ij} \in (-\infty, +\infty)$ into a valid probability $p_i \in [0, 1]$, the model utilizes the **Logit link function**:

$$\text{Odds}_i = \frac{p_i}{1 - p_i} \in [0, +\infty)$$

$$\text{logit}(p_i) = \ln(\text{Odds}_i) = \ln\left(\frac{p_i}{1 - p_i}\right) = \beta_0 + \sum_{j=1}^p \beta_j X_{ij}$$

### 2.2 Probability Recovery Function (Sigmoid)
Inverting the logit link yields the standard logistic sigmoid:

$$\hat{p}_i = \frac{e^{\mathbf{X}_i \boldsymbol{\beta}}}{1 + e^{\mathbf{X}_i \boldsymbol{\beta}}} = \frac{1}{1 + e^{-\mathbf{X}_i \boldsymbol{\beta}}}$$

### 2.3 Maximum Likelihood Estimation (MLE)
Parameters $\boldsymbol{\beta}$ are estimated by maximizing the Log-Likelihood function ($LL$):

$$LL(\boldsymbol{\beta}) = \sum_{i=1}^n \left[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \right]$$

- Numerical optimization is executed via Newton-Raphson or Iteratively Reweighted Least Squares (IRLS).
- **Model Deviance**: $D = -2 \cdot [LL(\text{Fitted}) - LL(\text{Saturated})]$.

## 3. DATA PREPROCESSING, PREMISES & AUDITING PROTOCOL

Before fitting any logistic model, you MUST execute and document the following statistical and commercial audits:

### 3.1 Categorical Predictors ($X$) & Dummy Encoding
1. **$n-1$ Dummy Rule**: For categorical variables with $n$ levels, encode strictly $n-1$ binary indicators to avoid the dummy variable trap.
2. **Reference Category Selection Protocol**:
   - **Prohibition 1**: NEVER select a reference category with $0\%$ or $100\%$ event rate (causes quasi-complete separation, infinite Odds Ratios, and exploding standard errors).
   - **Prohibition 2**: NEVER select a low-volume/sparse category as reference (causes wide confidence intervals and unstable base rates).
   - **Best Practice**: Select the category with the largest operational volume or the most intuitive business benchmark (e.g., standard plan, organic acquisition channel).
3. **High-Cardinality Treatment**: Use **Weight of Evidence (WoE)** and **Information Value (IV)** to bin and encode high-cardinality categories while preserving monotonic logit relationships:
   $$\text{WoE}_k = \ln\left(\frac{\% \text{ of Events in bin } k}{\% \text{ of Non-Events in bin } k}\right), \quad \text{IV} = \sum_{k=1}^K (\% \text{Events}_k - \% \text{Non-Events}_k) \times \text{WoE}_k$$
   - $\text{IV} < 0.02$: Useless for prediction.
   - $0.02 \le \text{IV} < 0.1$: Weak predictor.
   - $0.1 \le \text{IV} < 0.3$: Medium predictor.
   - $0.3 \le \text{IV} < 0.5$: Strong predictor.
   - $\text{IV} \ge 0.5$: Suspiciously high; audit for target leakage.

### 3.2 Numerical Predictors ($X$) & Empirical Logit Linearity Audit
The foundational assumption of logistic regression is that continuous predictors have a **linear relationship with the logit**, not with the raw probability.

**Empirical Logit Protocol**:
1. Partition the continuous variable $X$ into $K$ quantiles (deciles, $K=10$, ensuring $\ge 30$ observations per bin).
2. For each bin $k$, compute the mean value $\bar{X}_k$, the event count $E_k$, total count $N_k$, and empirical rate $\bar{p}_k = \frac{E_k}{N_k}$.
3. Calculate the **Empirical Logit** with continuity correction:
   $$\text{EmpLogit}_k = \ln\left(\frac{E_k + 0.5}{(N_k - E_k) + 0.5}\right)$$
4. Plot $\bar{X}_k$ vs $\text{EmpLogit}_k$:
   - **Monotonic / Linear**: Retain $X$ as a continuous feature.
   - **Polynomial / U-Shaped**: Add quadratic terms ($X^2$) or spline basis.
   - **Piecewise / Step Function**: Discretize into business-meaningful bins or apply WoE transformation.

### 3.3 Multicollinearity Diagnostics
- Compute **Variance Inflation Factor (VIF)** for all numeric features and dummies:
  $$\text{VIF}_j = \frac{1}{1 - R_j^2}$$
- **Threshold**: $\text{VIF} > 5.0$ indicates problematic collinearity; $\text{VIF} > 10.0$ requires elimination, aggregation, or L2 (Ridge) shrinkage.

### 3.4 Target Leakage & Out-Of-Time (OOT) Validation Setup
- **Target Leakage Prohibition**: Audit all candidate features to ensure no predictor contains information captured *after* the observation cutoff timestamp (e.g., support tickets opened post-cancellation).
- **Validation Partitioning**: In commercial setups, ALWAYS use **Out-of-Time (OOT) split** or temporal cohort splits alongside stratified K-Fold to evaluate model stability against macro-economic drift and seasonality.

## 4. MODEL ESTIMATION, SELECTION & BUSINESS INTERPRETATION

### 4.1 Statistical Significance & Goodness of Fit
- **Global Fit**: Likelihood Ratio Test (LR $\chi^2 = 2(LL_{\text{model}} - LL_{\text{null}})$).
- **Individual Coefficients**: Wald Test ($z = \frac{\hat{\beta}_j}{\text{SE}(\hat{\beta}_j)}$) with two-tailed $p$-values.
- **Model Selection**: Combine stepwise information criteria (AIC, BIC) with business domain constraints.

### 4.2 Parameter Interpretation Engine

#### A. Odds Ratios ($	ext{OR} = e^{\beta_j}$)
$$\text{OR}_j = e^{\beta_j}, \quad \% \Delta \text{Odds} = (e^{\beta_j} - 1) \times 100\%$$

- **Interpretation**: A 1-unit increase in $X_j$ multiplies the odds of event by $\text{OR}_j$, holding all other factors constant.
- **Inverted Ratio** (for $\text{OR} < 1$): $\text{OR}_{\text{inv}} = \frac{1}{\text{OR}_j}$ (e.g., "The reference group has $\text{OR}_{\text{inv}}$ times higher odds").
- **Scaled Steps ($k$-units)**: For a step of $k$ units (e.g., +$10$ years of age or +$R\$ 1,000$ in ticket):
  $$\text{OR}_{\Delta k} = e^{k \cdot \beta_j}$$
- **Confidence Intervals**: $\text{CI}_{95\%} = [\exp(\hat{\beta}_j - 1.96 \cdot \text{SE}), \exp(\hat{\beta}_j + 1.96 \cdot \text{SE})]$. If CI spans $1.0$, the effect is not statistically significant.

#### B. Average Marginal Effects (AME in Percentage Points - p.p.)
Business executives think in **probabilities and percentage points**, not in Odds. You MUST compute the Average Marginal Effect for every feature:

$$\text{AME}_j = \frac{1}{N} \sum_{i=1}^N \frac{\partial p_i}{\partial X_{ij}} = \frac{1}{N} \sum_{i=1}^N \hat{p}_i (1 - \hat{p}_i) \beta_j$$

- **Business Phrasing**: *"Holding all other variables at empirical distributions, an increase of 1 unit in $X_j$ increases the average probability of conversion by $\text{AME}_j \times 100$ percentage points (p.p.)."*

### 5.1 Objective 1: DECIDE (Classification & Unit Economics Optimization)
Used when every customer/lead requires an automated or operational discrete action (e.g., approve/reject credit, send expensive promotion, block fraudulent transaction).

#### Commercial Profit Matrix & Threshold Optimization ($c^*$)
Do **NOT** use arbitrary thresholds like $c = 0.5$. Optimize the cutoff $c^*$ by maximizing the financial objective function:

$$\mathbb{E}[\text{Net Profit}(c)] = \sum_{i=1}^N \Big[ \mathbf{1}_{\hat{p}_i \ge c} \cdot y_i \cdot (\text{Margin}_{\text{TP}}) - \mathbf{1}_{\hat{p}_i \ge c} \cdot (1 - y_i) \cdot (\text{Cost}_{\text{FP}}) - \mathbf{1}_{\hat{p}_i < c} \cdot y_i \cdot (\text{Loss}_{\text{FN}}) \Big]$$

Where:
- $\text{Margin}_{\text{TP}}$: Net profit generated by contacting/converting a true positive.
- $\text{Cost}_{\text{FP}}$: Wasted operational cost / marketing spend on a false positive.
- $\text{Loss}_{\text{FN}}$: Opportunity cost or lost LTV from failing to act on a true event.

#### Key Metrics:
- **Precision (Positive Predictive Value)**: $\frac{\text{TP}}{\text{TP} + \text{FP}}$ (Campaign efficiency).
- **Recall (Sensitivity / Capture Rate)**: $\frac{\text{TP}}{\text{TP} + \text{FN}}$ (Market coverage).
- **$F_{\beta}$ Score**: Parameterized harmonic mean balancing precision and recall according to business priorities ($\beta = 2$ favors recall, $\beta = 0.5$ favors precision).

---

### 5.2 Objective 2: ORDER (Ranking & Resource Allocation)
Used when operational capacity is fixed (e.g., outbound sales team can only dial 5,000 leads per day, or retention team can only handle top 5% highest churn-risk accounts).

#### Key Metrics & Tools:
1. **Cumulative Lift at Decile $k$**:
   $$\text{Lift}_k = \frac{\text{Response Rate in Top } k\%}{\text{Overall Baseline Response Rate}}$$
   - *Commercial Translation*: *"Targeting the top 20% ranked leads yields 3.4x more conversions than random dialing."*
2. **ROC-AUC & Gini Coefficient**:
   $$\text{Gini} = 2 \times \text{AUC} - 1$$
3. **Kolmogorov-Smirnov (KS) Statistic**:
   $$\text{KS} = \max_{c} |\text{TPR}(c) - \text{FPR}(c)|$$
   - Benchmark: $\text{KS} > 40\%$ indicates strong commercial discriminative power.

---

### 5.3 Objective 3: ESTIMATE (Calibration & Expected Portfolio Value)
Used when the raw probability $\hat{p}_i$ is directly plugged into financial calculations (e.g., Expected Loss in credit risk, dynamic pricing, churn-weighted lifetime value).

#### Expected Financial Value Formula:
$$\mathbb{E}[\text{Portfolio Impact}] = \sum_{i=1}^N \hat{p}_i \times \text{Monetary Exposure}_i$$

#### Calibration Diagnostics:
1. **Brier Score**: Mean squared difference between probabilities and actual binary outcomes:
   $$\text{Brier} = \frac{1}{N} \sum_{i=1}^N (\hat{p}_i - y_i)^2 \quad \in [0, 1]$$
2. **Expected Calibration Error (ECE)**:
   $$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} |\text{acc}(B_m) - \text{conf}(B_m)|$$
3. **Reliability Diagram**: Plot observed frequency vs. predicted probability per decile. Points must tightly hug the 45-degree identity line. If miscalibrated, apply isotonic regression or Platt scaling.

## 7. COMPLETE PRODUCTION PYTHON IMPLEMENTATION

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
import matplotlib.pyplot as plt
from statsmodels.stats.outliers_influence import variance_inflation_factor
from sklearn.metrics import (
    roc_auc_score, precision_score, recall_score,
    brier_score_loss, roc_curve
)
from sklearn.calibration import calibration_curve

class CommercialLogisticRegression:
    """
    Enterprise-grade Logistic Regression & GLM Auditor for Commercial Decision Making.
    Includes statistical checks, Odds Ratios, AME (p.p.), Unit Economics optimization,
    Tri-Objective performance metrics, and Executive Visual Dashboards.
    """
    def __init__(self, target_col, categorical_cols=None, numerical_cols=None):
        self.target_col = target_col
        self.categorical_cols = categorical_cols or []
        self.numerical_cols = numerical_cols or []
        self.model = None
        self.feature_names = []
        self.interpretation_table = None

    def audit_empirical_logit(self, df, q=10):
        """
        Audits linearity of continuous variables with empirical logit.
        """
        print("=" * 70)
        print("STEP 1: EMPIRICAL LOGIT LINEARITY AUDIT")
        print("=" * 70)
        audit_results = {}
        for num_col in self.numerical_cols:
            df_temp = df[[num_col, self.target_col]].dropna().copy()
            df_temp['bin'] = pd.qcut(df_temp[num_col], q=q, duplicates='drop')
            
            agg = df_temp.groupby('bin', observed=False).agg(
                n=('bin', 'count'),
                events=(self.target_col, 'sum'),
                mean_x=(num_col, 'mean'),
                rate=(self.target_col, 'mean')
            )
            # Continuity correction logit: ln((events + 0.5) / (non_events + 0.5))
            agg['non_events'] = agg['n'] - agg['events']
            agg['emp_logit'] = np.log((agg['events'] + 0.5) / (agg['non_events'] + 0.5))
            
            # Correlation between mean_x and empirical logit
            corr = np.corrcoef(agg['mean_x'], agg['emp_logit'])[0, 1]
            audit_results[num_col] = {
                'table': agg[['mean_x', 'n', 'rate', 'emp_logit']],
                'logit_correlation': corr
            }
            print(f"Feature '{num_col}' -> Pearson r with EmpLogit: {corr:.4f}")
        return audit_results

    def prepare_data(self, df):
        """
        Applies n-1 dummy encoding and formats design matrix X and target y.
        """
        df_encoded = pd.get_dummies(df, columns=self.categorical_cols, drop_first=True, dtype=float)
        
        # Identify feature columns
        non_feature = [self.target_col]
        all_features = [c for c in df_encoded.columns if c not in non_feature]
        
        X = sm.add_constant(df_encoded[all_features])
        y = df_encoded[self.target_col]
        self.feature_names = X.columns.tolist()
        return X, y

    def audit_multicollinearity(self, X):
        """
        Computes Variance Inflation Factor (VIF) for all features.
        """
        print("\n" + "=" * 70)
        print("STEP 2: MULTICOLLINEARITY (VIF) AUDIT")
        print("=" * 70)
        vif_df = pd.DataFrame()
        vif_df['Feature'] = X.columns
        vif_df['VIF'] = [variance_inflation_factor(X.values, i) for i in range(X.shape[1])]
        vif_df['Status'] = vif_df['VIF'].apply(lambda x: 'OK' if x < 5.0 else ('WARNING (>5)' if x < 10.0 else 'CRITICAL (>10)'))
        print(vif_df[vif_df['Feature'] != 'const'].to_string(index=False))
        return vif_df

    def fit(self, X_train, y_train):
        """
        Fits Logistic Regression via MLE using Statsmodels.
        """
        print("\n" + "=" * 70)
        print("STEP 3: MAXIMUM LIKELIHOOD ESTIMATION (GLM LOGIT)")
        print("=" * 70)
        self.model = sm.Logit(y_train, X_train).fit(disp=False)
        print(self.model.summary())
        return self.model

    def build_business_interpretation_table(self):
        """
        Extracts Coefficients, Odds Ratios, Inverted Odds, and Average Marginal Effects.
        """
        print("\n" + "=" * 70)
        print("STEP 4: COMMERCIAL INTERPRETATION ENGINE (OR & MARGINAL EFFECTS)")
        print("=" * 70)
        params = self.model.params
        conf_int = self.model.conf_int()
        pvalues = self.model.pvalues
        
        # Calculate Average Marginal Effects (AME)
        margeff = self.model.get_margeff(at='overall')
        ame_series = pd.Series(margeff.margeff, index=params.index[1:])
        
        interp = pd.DataFrame({
            'Beta Coef': params,
            'Std Error': self.model.bse,
            'Odds Ratio (e^b)': np.exp(params),
            '% Delta Odds': (np.exp(params) - 1) * 100,
            'OR 95% CI Lower': np.exp(conf_int[0]),
            'OR 95% CI Upper': np.exp(conf_int[1]),
            'AME (p.p.)': ame_series * 100, # converted to percentage points
            'p-value': pvalues
        })
        
        # Inverted odds for negative relationships
        interp['Inverted OR (1/OR)'] = interp['Odds Ratio (e^b)'].apply(
            lambda x: (1.0 / x) if x < 1.0 else np.nan
        )
        self.interpretation_table = interp
        print(interp.round(4).to_string())
        return interp

    def optimize_financial_threshold(self, y_true, y_pred_prob, margin_tp, cost_fp, loss_fn):
        """
        Optimizes classification cut-off threshold c* using Unit Economics.
        """
        print("\n" + "=" * 70)
        print("STEP 5: FINANCIAL THRESHOLD OPTIMIZATION (UNIT ECONOMICS)")
        print("=" * 70)
        thresholds = np.linspace(0.01, 0.99, 100)
        best_profit = -np.inf
        best_c = 0.5
        profit_curve = []

        for c in thresholds:
            y_pred = (y_pred_prob >= c).astype(int)
            tp = np.sum((y_pred == 1) & (y_true == 1))
            fp = np.sum((y_pred == 1) & (y_true == 0))
            fn = np.sum((y_pred == 0) & (y_true == 1))
            
            # Net expected financial outcome
            total_profit = (tp * margin_tp) - (fp * cost_fp) - (fn * loss_fn)
            profit_curve.append({'threshold': c, 'profit': total_profit, 'tp': tp, 'fp': fp, 'fn': fn})
            
            if total_profit > best_profit:
                best_profit = total_profit
                best_c = c

        baseline_profit = next(item['profit'] for item in profit_curve if abs(item['threshold'] - 0.5) < 0.015)
        print(f"Optimal Threshold (c*):   {best_c:.3f}")
        print(f"Maximum Net Profit:       R$ {best_profit:,.2f}")
        print(f"Baseline Profit (c=0.5):   R$ {baseline_profit:,.2f}")
        print(f"Incremental Financial Gain: R$ {(best_profit - baseline_profit):,.2f}")
        return best_c, best_profit, pd.DataFrame(profit_curve)

    def evaluate_tri_objective(self, y_true, y_pred_prob, c_opt=0.5):
        """
        Comprehensive evaluation across the 3 business objectives: DECIDE, ORDER, ESTIMATE.
        """
        print("\n" + "=" * 70)
        print("STEP 6: TRI-OBJECTIVE PERFORMANCE AUDIT (OUT-OF-SAMPLE / OOT)")
        print("=" * 70)
        
        # 1. ESTIMATE (Probability Calibration)
        brier = brier_score_loss(y_true, y_pred_prob)
        
        # 2. ORDER (Ranking & Prioritization)
        auc = roc_auc_score(y_true, y_pred_prob)
        gini = 2 * auc - 1
        fpr, tpr, _ = roc_curve(y_true, y_pred_prob)
        ks = np.max(tpr - fpr)
        
        # Decile Lift Table
        df_eval = pd.DataFrame({'y_true': y_true.values if hasattr(y_true, 'values') else y_true, 'y_prob': y_pred_prob})
        df_eval['decile'] = pd.qcut(df_eval['y_prob'], q=10, labels=False, duplicates='drop')
        df_eval['decile'] = 10 - df_eval['decile'] # 1 is highest prob
        lift_table = df_eval.groupby('decile').agg(
            total=('y_true', 'count'),
            events=('y_true', 'sum'),
            rate=('y_true', 'mean')
        )
        base_rate = df_eval['y_true'].mean()
        lift_table['lift'] = lift_table['rate'] / base_rate
        lift_table['cum_events'] = lift_table['events'].cumsum()
        lift_table['cum_capture_rate'] = (lift_table['cum_events'] / df_eval['y_true'].sum()) * 100
        
        # 3. DECIDE (Threshold Metrics at c_opt)
        y_pred = (y_pred_prob >= c_opt).astype(int)
        precision = precision_score(y_true, y_pred, zero_division=0)
        recall = recall_score(y_true, y_pred, zero_division=0)
        
        print(f"[ESTIMATE] Brier Score:             {brier:.4f} (Closer to 0 is better)")
        print(f"[ORDER]    ROC-AUC:                 {auc:.4f}")
        print(f"[ORDER]    Gini Coefficient:        {gini:.4f}")
        print(f"[ORDER]    Kolmogorov-Smirnov (KS): {ks * 100:.2f}%")
        print(f"[ORDER]    Top Decile Lift:         {lift_table.loc[1, 'lift']:.2f}x baseline")
        print(f"[DECIDE]   Precision (c={c_opt:.2f}):    {precision * 100:.2f}%")
        print(f"[DECIDE]   Recall (c={c_opt:.2f}):       {recall * 100:.2f}%\n")
        
        print("--- Cumulative Decile Lift & Capture Table ---")
        print(lift_table[['total', 'events', 'rate', 'lift', 'cum_capture_rate']].round(3).to_string())
        
        return {
            'brier_score': brier,
            'auc': auc,
            'gini': gini,
            'ks_stat': ks,
            'lift_table': lift_table,
            'precision': precision,
            'recall': recall
        }

    def plot_commercial_dashboard(self, y_true, y_pred_prob, profit_curve_df, best_c, save_path=None):
        """
        Generates an executive 2x2 visual dashboard for business decision makers.
        """
        fig, axes = plt.subplots(2, 2, figsize=(15, 11))
        plt.subplots_adjust(hspace=0.32, wspace=0.25)
        
        # 1. Net Profit vs. Threshold
        ax1 = axes[0, 0]
        ax1.plot(profit_curve_df['threshold'], profit_curve_df['profit'], color='#1f77b4', lw=2.5, label='Curva de Lucro Esperado')
        ax1.axvline(best_c, color='#d62728', linestyle='--', lw=1.8, label=f'Corte Ótimo (c* = {best_c:.2f})')
        ax1.axvline(0.5, color='gray', linestyle=':', lw=1.2, label='Baseline Padrão (c = 0.50)')
        ax1.set_title("1. Decidir: Otimização Financeira de Threshold", fontsize=12, fontweight='bold')
        ax1.set_xlabel("Ponto de Corte (Threshold c)")
        ax1.set_ylabel("Lucro Líquido Esperado (R$)")
        ax1.grid(True, alpha=0.3)
        ax1.legend(loc='best', fontsize=9)

        # 2. Cumulative Gains / Lift Curve
        ax2 = axes[0, 1]
        df_eval = pd.DataFrame({'y': y_true.values if hasattr(y_true, 'values') else y_true, 'prob': y_pred_prob})
        df_eval['decile'] = pd.qcut(df_eval['prob'], q=10, labels=False, duplicates='drop')
        df_eval['decile'] = 10 - df_eval['decile']
        cum_gains = (df_eval.groupby('decile')['y'].sum().cumsum() / df_eval['y'].sum()) * 100
        
        ax2.plot(range(1, len(cum_gains) + 1), cum_gains, marker='o', color='#2ca02c', lw=2.5, label='Modelo Logístico')
        ax2.plot(range(1, len(cum_gains) + 1), np.linspace(10, 100, len(cum_gains)), color='gray', linestyle=':', lw=1.5, label='Seleção Aleatória (Baseline)')
        ax2.set_title("2. Ordenar: Curva de Ganho Cumulativo por Decil", fontsize=12, fontweight='bold')
        ax2.set_xlabel("Decil da População (Top leads ordenados)")
        ax2.set_ylabel("% Total de Conversões Capturadas")
        ax2.set_xticks(range(1, len(cum_gains) + 1))
        ax2.grid(True, alpha=0.3)
        ax2.legend(loc='lower right', fontsize=9)

        # 3. Commercial Levers: Average Marginal Effects (AME in p.p.)
        ax3 = axes[1, 0]
        if self.interpretation_table is not None:
            ame_data = self.interpretation_table.dropna(subset=['AME (p.p.)']).copy()
            ame_data = ame_data.sort_values(by='AME (p.p.)')
            colors = ['#d62728' if x < 0 else '#2ca02c' for x in ame_data['AME (p.p.)']]

            ax3.set_xlabel("Variação Média na Probabilidade (Pontos Percentuais - p.p.)")
            ax3.grid(True, alpha=0.3)

        # 4. Reliability Diagram / Probability Calibration
        ax4 = axes[1, 1]
        prob_true, prob_pred = calibration_curve(y_true, y_pred_prob, n_bins=10)

        ax4.plot([0, 1], [0, 1], linestyle='--', color='gray', lw=1.5, label='Calibração Perfeita (45°)')
        ax4.set_title("4. Estimar: Curva de Confiabilidade / Calibração", fontsize=12, fontweight='bold')
        ax4.set_xlabel("Probabilidade Predita")
        ax4.set_ylabel("Frequência Real de Conversão")
        ax4.grid(True, alpha=0.3)
        ax4.legend(loc='upper left', fontsize=9)
```
