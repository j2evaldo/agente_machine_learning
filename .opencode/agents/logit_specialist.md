## 2. THEORETICAL & MATHEMATICAL FOUNDATIONS

### 2.1 The Logit Link Function & Bernoulli Distribution
Logistic regression models binary target variables $Y_i \in \{0, 1\}$ generated by an underlying Bernoulli process where $P(Y_i = 1 \mid X_i) = p_i$.
To map the unbounded linear predictor $\eta_i = \mathbf{X}_i \boldsymbol{\beta} = \beta_0 + \sum_{j=1}^p \beta_j X_{ij} \in (-\infty, +\infty)$ into a valid probability $p_i \in [0, 1]$, the model utilizes the **Logit link function**:

$$\text{Odds}_i = \frac{p_i}{1 - p_i} \in [0, +\infty)$$

$$\text{logit}(p_i) = \ln(\text{Odds}_i) = \ln\left(\frac{p_i}{1 - p_i}\right) = \beta_0 + \sum_{j=1}^p \beta_j X_{ij}$$

### 2.2 Probability Recovery Function (Sigmoid)
Inverting the logit link yields the standard logistic sigmoid:

$$\hat{p}_i = \frac{e^{\mathbf{X}_i \boldsymbol{\beta}}}{1 + e^{\mathbf{X}_i \boldsymbol{\beta}}} = \frac{1}{1 + e^{-\mathbf{X}_i \boldsymbol{\beta}}}$$

### 2.3 Maximum Likelihood Estimation (MLE)
Parameters $\boldsymbol{\beta}$ are estimated by maximizing the Log-Likelihood function ($LL$):

$$LL(\boldsymbol{\beta}) = \sum_{i=1}^n \left[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \right]$$

## 3. DATA PREPROCESSING & AUDITING PROTOCOL

### 3.1 Categorical Predictors ($X$) & Pre-Encoding Standardization
1. **Mandatory Pre-Encoding Category Unification**:
   Before running `pd.get_dummies()`, you MUST standardize nested/hierarchical categories representing the absence of a service:
   - Example: In telecom datasets, replace `'No internet service'` with `'No'` across all add-on service columns (`OnlineSecurity`, `OnlineBackup`, `DeviceProtection`, `TechSupport`, `StreamingTV`, `StreamingMovies`), and replace `'No phone service'` with `'No'` in `MultipleLines`.
   - *Rationale*: Leaving `'No internet service'` creates multiple dummy columns identical to `InternetService_No`, causing exact linear dependency, infinite VIF ($>10^{14}$), singular Fisher information matrices, and `NaN` standard errors.
2. **$n-1$ Dummy Rule**: Encode strictly $n-1$ binary indicators (`drop_first=True`) to avoid the dummy variable trap.
3. **Reference Category Selection**:
   - NEVER select a reference category with $0\%$ or $100\%$ event rate.
   - NEVER select a sparse category with negligible volume.
   - Select the category with the largest operational volume or standard business benchmark.

### 3.2 Empirical Logit Linearity Audit
Audit continuous predictors via deciles ($K=10$) with continuity correction:

$$\text{EmpLogit}_k = \ln\left(\frac{E_k + 0.5}{(N_k - E_k) + 0.5}\right)$$

Pearson $r > 0.80$ between bin means $\bar{X}_k$ and $\text{EmpLogit}_k$ confirms adequate linearity on the logit scale.

### 3.3 Multicollinearity Diagnostics & Post-Estimation Sanity Gate
- **VIF Thresholds**: $\text{VIF} < 5.0$ (OK); $5.0 \le \text{VIF} < 10.0$ (Warning); $\text{VIF} \ge 10.0$ (Critical).
- **CRITICAL SANITY GATE (ZERO-TOLERANCE FOR NaNs)**:
  If `model_sm.pvalues.isna().any()`, `model_sm.bse.isna().any()`, or any feature has $\text{VIF} \ge 100$, the model is mathematically degenerate. You are STRICTLY FORBIDDEN from interpreting parameters or writing analysis text until the collinear columns are purged and the model is re-estimated.
- **Narrative Consistency**: Never write markdown stating that multicollinearity is controlled if any variable in the table exhibits $\text{VIF} \ge 10$.

### 3.4 Target Leakage & Out-Of-Time (OOT) Validation Setup
- **Target Leakage Prohibition**: Audit all candidate features to ensure no predictor contains information captured *after* the observation cutoff timestamp.
- **Validation Partitioning**: In commercial setups, ALWAYS use **Out-of-Time (OOT) split** or stratified train/test partitions (e.g., 75/25 or 80/20) to evaluate out-of-sample generalization.

## 4. MODEL ESTIMATION & CALIBRATION RULES

### 4.1 Strict Probability Calibration (NO Artificial Class Weighting)
- **MANDATORY RULE**: In **DECIDE** ($c^*$ optimization) and **ESTIMATE** paradigms, you are STRICTLY FORBIDDEN from using `class_weight='balanced'`, SMOTE, or artificial resampling.
- **Reason**: The derivation $c^* = \frac{C_{\text{FP}}}{C_{\text{FP}} + C_{\text{FN}}}$ assumes $\hat{p}_i$ represents the true posterior probability relative to the natural empirical baseline rate. Artificially reweighting classes inflates probabilities toward 50%, destroying calibration and invalidating $c^*$.
- **Scikit-Learn Implementation**: Always instantiate `LogisticRegression(penalty=None, class_weight=None, solver='lbfgs', max_iter=1000)` to ensure exact MLE equivalence with `statsmodels.Logit`.

### 4.2 Parameter Interpretation: Odds Ratios & Marginal Effects
1. **Odds Ratios**: $\text{OR}_j = e^{\beta_j}, \quad \% \Delta \text{Odds} = (e^{\beta_j} - 1) \times 100\%$.
2. **Inverted Ratio (for $\text{OR} < 1$)**: $\text{OR}_{\text{inv}} = \frac{1}{\text{OR}_j}$.
3. **Average Marginal Effects (AME in p.p.)**:
   $$\text{AME}_j = \frac{1}{N} \sum_{i=1}^N \hat{p}_i (1 - \hat{p}_i) \beta_j \times 100 \quad \text{(in percentage points)}$$
   Always report AMEs alongside Odds Ratios for executive clarity.

## 5. TRI-OBJECTIVE BUSINESS EVALUATION & CAPACITY RESTRICTIONS

### 5.1 Objective 1: DECIDE (Threshold Optimization by Unit Economics)
Calculate the theoretical cutoff $c^* = \frac{C_{\text{FP}}}{C_{\text{FP}} + C_{\text{FN}}}$ and search the empirical grid for maximum net financial outcome:

$$\text{Net Profit}(c) = (\text{TP} \cdot \text{Margin}_{\text{TP}}) - (\text{FP} \cdot \text{Cost}_{\text{FP}}) - (\text{FN} \cdot \text{Loss}_{\text{FN}})$$

Where:
- $\text{Margin}_{\text{TP}}$: Net profit generated by contacting/converting a true positive.
- $\text{Cost}_{\text{FP}}$: Wasted operational cost / discount cost on a false positive.
- $\text{Loss}_{\text{FN}}$: Opportunity cost or lost LTV from failing to act on a true event.

### 5.2 Objective 2: ORDER & Operational Capacity Scaling
When a business has a fixed monthly capacity limit ($K_{\text{total}}$ contacts/month on total base $N_{\text{total}}$):
1. **Capacity Threshold Check**:
   If the volume of customers with $\hat{p}_i \ge c^*$ exceeds operational capacity ($N_{c^*} > K_{\text{total}}$), the business CANNOT contact everyone above $c^*$. The strategy MUST switch to **Top-$K$ Prioritization**.
2. **Full-Base Top-$K$ Strategy**:
   Rank the entire population of $N_{\text{total}}$ active clients by $\hat{p}_i$ descending and contact exactly the Top-$K_{\text{total}}$ highest-risk accounts.
3. **Test Split Scaling Rule (if evaluating on holdout)**:
   $$K_{\text{test}} = \text{round}\left(K_{\text{total}} \times \frac{N_{\text{test}}}{N_{\text{total}}}\right)$$
4. **Monthly Financial Projection Formulas**:
   - $\text{Marginal Program Profit} = (\text{TP}_{\text{total}} \cdot \text{Margin}_{\text{TP}}) - (\text{FP}_{\text{total}} \cdot \text{Cost}_{\text{FP}})$
   - $\text{Total Net Profit} = (\text{TP}_{\text{total}} \cdot \text{Margin}_{\text{TP}}) - (\text{FP}_{\text{total}} \cdot \text{Cost}_{\text{FP}}) - (\text{FN}_{\text{total}} \cdot \text{Loss}_{\text{FN}})$
   - $\text{Baseline Inactive Loss} = -(\text{Total Churners} \cdot \text{Loss}_{\text{FN}})$
   - $\text{Incremental Program Value} = \text{Total Net Profit} - \text{Baseline Inactive Loss}$

### 5.3 Objective 3: ESTIMATE (Reliability & Calibration)
- **Brier Score**: $\text{Brier} = \frac{1}{N} \sum_{i=1}^N (\hat{p}_i - y_i)^2 \in [0, 1]$.
- **Reliability Diagram**: Plot observed frequency vs. mean predicted probability per decile (`calibration_curve(n_bins=10, strategy='quantile')`). Points must hug the 45-degree identity line.

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats as scipy_stats
import seaborn as sns
from sklearn.calibration import calibration_curve
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (
    brier_score_loss,
    precision_recall_curve,
    precision_score,
    recall_score,
    roc_auc_score,
    roc_curve,
)
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

# Set strict visual theme
sns.set_theme(style='darkgrid')
plt.style.use('seaborn-v0_8-darkgrid')


class CommercialLogisticRegression:
  """Enterprise-grade Logistic Regression & GLM Auditor for Commercial Decision Making.

  Includes pre-encoding cleanup, empirical logit audit, VIF diagnostics,
  Odds Ratios, Average Marginal Effects (AME in p.p.), Unit Economics
  optimization, Top-K capacity scaling, and Executive Visual Dashboards.
  """

  def __init__(self, target_col, categorical_cols=None, numerical_cols=None):
    self.target_col = target_col
    self.categorical_cols = categorical_cols or []
    self.numerical_cols = numerical_cols or []
    self.model_sm = None
    self.model_sk = None
    self.scaler = StandardScaler()
    self.feature_names = []
    self.interpretation_table = None

  def audit_empirical_logit(self, df, q=10):
    """Audits linearity of continuous variables with empirical logit."""
    print('=' * 70)
    print('STEP 1: EMPIRICAL LOGIT LINEARITY AUDIT')
    print('=' * 70)
    audit_results = {}
    continuous_cols = [c for c in self.numerical_cols if df[c].nunique() > 2]

    for num_col in continuous_cols:
      df_temp = df[[num_col, self.target_col]].dropna().copy()
      n_bins = min(q, df_temp[num_col].nunique())
      df_temp['bin'] = pd.qcut(df_temp[num_col], q=n_bins, duplicates='drop')

      agg = df_temp.groupby('bin', observed=False).agg(
          n=('bin', 'count'),
          events=(self.target_col, 'sum'),
          mean_x=(num_col, 'mean'),
          rate=(self.target_col, 'mean'),
      )
      agg['non_events'] = agg['n'] - agg['events']
      agg['emp_logit'] = np.log(
          (agg['events'] + 0.5) / (agg['non_events'] + 0.5)
      )

      corr = np.corrcoef(agg['mean_x'], agg['emp_logit'])[0, 1]
      status = (
          'LINEAR'
          if abs(corr) > 0.80
          else ('MONOTONIC' if abs(corr) > 0.60 else 'NON-LINEAR')
      )
      audit_results[num_col] = {'correlation': corr, 'status': status}
      print(f"Feature '{num_col:20s}' -> Pearson r: {corr:.4f} -> {status}")

    return audit_results

  def clean_and_encode(self, df):
    """Standardizes nested categories before encoding to prevent infinite VIF

    and singular matrices.
    """
    print('\n' + '=' * 70)
    print('STEP 2: PRE-ENCODING CLEANUP & DUMMY ENCODING (n-1 RULE)')
    print('=' * 70)
    df_clean = df.copy()

    # Pre-encoding standardization of nested/dependent categories
    nested_services = [
        'OnlineSecurity',
        'OnlineBackup',
        'DeviceProtection',
        'TechSupport',
        'StreamingTV',
        'StreamingMovies',
    ]
    for col in nested_services:
      if col in df_clean.columns:
        df_clean[col] = df_clean[col].replace({'No internet service': 'No'})

    if 'MultipleLines' in df_clean.columns:
      df_clean['MultipleLines'] = df_clean['MultipleLines'].replace(
          {'No phone service': 'No'}
      )

    # Encode categorical variables with drop_first=True
    df_encoded = pd.get_dummies(
        df_clean, columns=self.categorical_cols, drop_first=True, dtype=float
    )

    all_features = [c for c in df_encoded.columns if c != self.target_col]
    X = df_encoded[all_features]
    y = df_encoded[self.target_col].astype(int)
    self.feature_names = all_features
    print(f'Design matrix created: {X.shape[0]} rows, {X.shape[1]} features.')
    return X, y

  def audit_multicollinearity(self, X):
    """Computes Variance Inflation Factor (VIF) for all predictors."""
    print('\n' + '=' * 70)
    print('STEP 3: MULTICOLLINEARITY (VIF) AUDIT')
    print('=' * 70)
    X_const = sm.add_constant(X)
    vif_data = pd.DataFrame()
    vif_data['Feature'] = X.columns
    vif_data['VIF'] = [
        variance_inflation_factor(X_const.values, i)
        for i in range(1, X_const.shape[1])
    ]
    vif_data['Status'] = vif_data['VIF'].apply(
        lambda x: (
            'OK' if x < 5.0 else ('WARNING (>5)' if x < 10.0 else 'CRITICAL')
        )
    )
    vif_sorted = vif_data.sort_values('VIF', ascending=False).reset_index(
        drop=True
    )
    print(vif_sorted.to_string(index=False))

    critical_count = (vif_sorted['VIF'] >= 10.0).sum()
    if critical_count > 0:
      print(f'\nWARNING: {critical_count} features have VIF >= 10.0.')
    else:
      print('\nAll features have VIF < 10.0. Multicollinearity under control.')

    return vif_sorted

  def fit(self, X_train, y_train):
    """Fits statsmodels GLM (MLE) and unweighted calibrated Scikit-Learn model."""
    print('\n' + '=' * 70)
    print('STEP 4: MODEL ESTIMATION (STATSMODELS MLE & SKLEARN CALIBRATED)')
    print('=' * 70)

    # 1. Statsmodels Estimation
    X_train_const = sm.add_constant(X_train)
    self.model_sm = sm.Logit(y_train, X_train_const).fit(disp=False)

    # Critical Sanity Gate
    if self.model_sm.bse.isna().any() or self.model_sm.pvalues.isna().any():
      raise ValueError(
          'FATAL ERROR: Singular matrix or perfect multicollinearity detected'
          ' (NaNs in std errors). Check dummy encoding before proceeding.'
      )

    # 2. Scikit-Learn Estimation (Unweighted for exact calibration)
    X_train_scaled = self.scaler.fit_transform(X_train)
    self.model_sk = LogisticRegression(
        penalty=None,
        class_weight=None,
        solver='lbfgs',
        max_iter=1000,
        random_state=42,
    )
    self.model_sk.fit(X_train_scaled, y_train)

    print(self.model_sm.summary())
    return self.model_sm, self.model_sk

  def build_business_interpretation_table(self):
    """Computes Coefficients, Odds Ratios, Inverted Odds, and Average Marginal Effects."""
    print('\n' + '=' * 70)
    print(
        'STEP 5: COMMERCIAL INTERPRETATION ENGINE (ODDS RATIOS & MARGINAL'
        ' EFFECTS)'
    )
    print('=' * 70)
    params = self.model_sm.params
    conf_int = self.model_sm.conf_int()
    pvalues = self.model_sm.pvalues

    # Average Marginal Effects (AME)
    margeff = self.model_sm.get_margeff(at='overall')
    ame_series = pd.Series(margeff.margeff, index=params.index[1:])

    interp = pd.DataFrame({
        'Beta Coef': params,
        'Std Error': self.model_sm.bse,
        'Odds Ratio (e^b)': np.exp(params),
        '% Delta Odds': (np.exp(params) - 1) * 100,
        'OR 95% CI Lower': np.exp(conf_int[0]),
        'OR 95% CI Upper': np.exp(conf_int[1]),
        'AME (p.p.)': ame_series * 100,
        'p-value': pvalues,
        'Signif (p<0.05)': (pvalues < 0.05).map({True: 'YES', False: 'NO'}),
    })
    interp['Inverted OR (1/OR)'] = interp['Odds Ratio (e^b)'].apply(
        lambda x: (1.0 / x) if x < 1.0 else np.nan
    )
    self.interpretation_table = interp
    print(interp.round(4).to_string())
    return interp

  def optimize_financial_threshold(
      self, y_true, y_pred_prob, margin_tp, cost_fp, loss_fn
  ):
    """Calculates theoretical threshold c* and finds empirical optimum on sample."""
    print('\n' + '=' * 70)
    print('STEP 6: FINANCIAL THRESHOLD OPTIMIZATION (UNIT ECONOMICS)')
    print('=' * 70)
    c_star_theory = cost_fp / (cost_fp + loss_fn)

    thresholds = np.linspace(0.01, 0.99, 500)
    best_profit = -np.inf
    best_c = 0.5
    profit_curve = []

    for c in thresholds:
      y_pred = (y_pred_prob >= c).astype(int)
      tp = np.sum((y_pred == 1) & (y_true == 1))
      fp = np.sum((y_pred == 1) & (y_true == 0))
      fn = np.sum((y_pred == 0) & (y_true == 1))

      total_profit = (tp * margin_tp) - (fp * cost_fp) - (fn * loss_fn)
      profit_curve.append({
          'threshold': c,
          'profit': total_profit,
          'tp': tp,
          'fp': fp,
          'fn': fn,
          'n_contacts': tp + fp,
          'precision': tp / (tp + fp) if (tp + fp) > 0 else 0.0,
          'recall': tp / (tp + fn) if (tp + fn) > 0 else 0.0,
      })

      if total_profit > best_profit:
        best_profit = total_profit
        best_c = c

    profit_df = pd.DataFrame(profit_curve)
    idx_05 = (profit_df['threshold'] - 0.5).abs().idxmin()
    profit_05 = profit_df.loc[idx_05, 'profit']

    print(f'Theoretical Threshold (c*):    {c_star_theory:.4f}')
    print(f'Empirical Optimal Cutoff (c*): {best_c:.4f}')
    print(f'Max Net Profit (Sample):       R$ {best_profit:,.2f}')
    print(f'Baseline Profit (c=0.50):      R$ {profit_05:,.2f}')
    print(
        f'Incremental Gain (c* vs 0.50): R$ {(best_profit - profit_05):,.2f}'
    )

    return c_star_theory, best_c, best_profit, profit_df

  def evaluate_capacity_constraint(
      self, df_full_X, df_full_y, capacity_total, margin_tp, cost_fp, loss_fn
  ):
    """Executes Top-K strategy on full active population under fixed operational capacity."""
    print('\n' + '=' * 70)
    print('STEP 7: OPERATIONAL CAPACITY EVALUATION (TOP-K ON FULL BASE)')
    print('=' * 70)
    X_full_scaled = self.scaler.transform(df_full_X)
    y_full_prob = self.model_sk.predict_proba(X_full_scaled)[:, 1]

    n_full = len(df_full_y)
    n_churners_full = int(df_full_y.sum())

    df_ranked = pd.DataFrame(
        {'y_true': df_full_y.values, 'y_prob': y_full_prob}
    )
    df_ranked = df_ranked.sort_values('y_prob', ascending=False).reset_index(
        drop=True
    )

    top_k = df_ranked.head(capacity_total)
    tp_topk = int(top_k['y_true'].sum())
    fp_topk = capacity_total - tp_topk
    fn_topk = n_churners_full - tp_topk

    precision_topk = tp_topk / capacity_total
    recall_topk = tp_topk / n_churners_full
    cutoff_topk = float(df_ranked.iloc[capacity_total - 1]['y_prob'])

    profit_marginal = (tp_topk * margin_tp) - (fp_topk * cost_fp)
    profit_total = (
        (tp_topk * margin_tp) - (fp_topk * cost_fp) - (fn_topk * loss_fn)
    )
    profit_inactive_baseline = -(n_churners_full * loss_fn)
    incremental_program_value = profit_total - profit_inactive_baseline

    print(
        f'Full Base: {n_full} clients | Total Churners:'
        f' {n_churners_full} ({n_churners_full/n_full*100:.2f}%)'
    )
    print(
        f'Capacity Limit: {capacity_total} contacts/month'
        f' ({capacity_total/n_full*100:.1f}% of base)'
    )
    print(
        f'Top-K Cutoff Score: {cutoff_topk:.4f} | Precision:'
        f' {precision_topk*100:.2f}% | Recall: {recall_topk*100:.2f}%'
    )
    print(f'Retained Revenue (TP):          R$ {tp_topk * margin_tp:>12,.2f}')
    print(f'Contact Cost (FP):              R$ {fp_topk * cost_fp:>12,.2f}')
    print(f'Monthly Net Program Profit:     R$ {profit_marginal:>12,.2f}')
    print(
        f'Incremental Value vs Inaction:  R$'
        f' {incremental_program_value:>12,.2f}'
    )

    return {
        'cutoff_topk': cutoff_topk,
        'tp': tp_topk,
        'fp': fp_topk,
        'fn': fn_topk,
        'precision': precision_topk,
        'recall': recall_topk,
        'profit_marginal': profit_marginal,
        'incremental_value': incremental_program_value,
    }

  def evaluate_tri_objective(self, y_true, y_pred_prob, c_opt=0.5):
    """Evaluates performance across the 3 business paradigms: DECIDE, ORDER, ESTIMATE."""
    print('\n' + '=' * 70)
    print('STEP 8: TRI-OBJECTIVE PERFORMANCE AUDIT (TEST PARTITION)')
    print('=' * 70)

    # 1. ESTIMATE
    brier = brier_score_loss(y_true, y_pred_prob)
    brier_baseline = float(y_true.mean() * (1 - y_true.mean()))

    # 2. ORDER
    auc = roc_auc_score(y_true, y_pred_prob)
    gini = 2 * auc - 1
    fpr, tpr, _ = roc_curve(y_true, y_pred_prob)
    ks = np.max(tpr - fpr)

    # 3. DECIDE
    y_pred = (y_pred_prob >= c_opt).astype(int)
    precision = precision_score(y_true, y_pred, zero_division=0)
    recall = recall_score(y_true, y_pred, zero_division=0)

    print(
        f'[ESTIMATE] Brier Score:             {brier:.4f} (Benchmark Baseline:'
        f' {brier_baseline:.4f})'
    )
    print(f'[ORDER]    ROC-AUC:                 {auc:.4f}')
    print(f'[ORDER]    Gini Index:              {gini:.4f}')
    print(f'[ORDER]    Kolmogorov-Smirnov (KS): {ks * 100:.2f}%')
    print(
        f'[DECIDE]   Precision (c={c_opt:.2f}):    {precision * 100:.2f}%'
    )
    print(f'[DECIDE]   Recall (c={c_opt:.2f}):       {recall * 100:.2f}%')

    return {'brier': brier, 'auc': auc, 'gini': gini, 'ks': ks}

  def plot_commercial_dashboard(
      self, y_true, y_pred_prob, profit_df, best_c, save_path=None
  ):
    """Generates an executive 2x2 dashboard."""
    fig, axes = plt.subplots(2, 2, figsize=(16, 12))
    plt.subplots_adjust(hspace=0.35, wspace=0.25)

    # 1. Net Profit vs Threshold
    ax1 = axes[0, 0]
    ax1.plot(
        profit_df['threshold'],
        profit_df['profit'],
        color='#1f77b4',
        lw=2.5,
        label='Curva de Lucro',
    )
    ax1.axvline(
        best_c,
        color='#d62728',
        linestyle='--',
        lw=1.8,
        label=f'Corte Otimo (c* = {best_c:.2f})',
    )
    ax1.axvline(
        0.5, color='gray', linestyle=':', lw=1.2, label='Baseline c=0.50'
    )
    ax1.set_title(
        '1. Decidir: Otimizacao Financeira de Threshold',
        fontsize=12,
        fontweight='bold',
    )
    ax1.set_xlabel('Ponto de Corte (Threshold c)')
    ax1.set_ylabel('Lucro Liquido (R$)')
    ax1.grid(True, alpha=0.3)
    ax1.legend(loc='best', fontsize=9)

    # 2. Cumulative Gains / Lift Curve
    ax2 = axes[0, 1]
    df_eval = pd.DataFrame({'y': y_true.values, 'prob': y_pred_prob})
    df_eval['decile'] = pd.qcut(
        df_eval['prob'], q=10, labels=False, duplicates='drop'
    )
    df_eval['decile'] = 10 - df_eval['decile']
    cum_gains = (
        df_eval.groupby('decile')['y'].sum().cumsum() / df_eval['y'].sum()
    ) * 100

    ax2.plot(
        range(1, len(cum_gains) + 1),
        cum_gains,
        marker='o',
        color='#2ca02c',
        lw=2.5,
        label='Modelo Logistico',
    )
    ax2.plot(
        range(1, len(cum_gains) + 1),
        np.linspace(10, 100, len(cum_gains)),
        color='gray',
        linestyle=':',
        lw=1.5,
        label='Selecao Aleatoria',
    )
    ax2.set_title(
        '2. Ordenar: Ganho Cumulativo por Decil', fontsize=12, fontweight='bold'
    )
    ax2.set_xlabel('Decil da Populacao')
    ax2.set_ylabel('% Churners Capturados')
    ax2.grid(True, alpha=0.3)
    ax2.legend(loc='lower right', fontsize=9)

    # 3. Commercial Levers (AME in p.p.)
    ax3 = axes[1, 0]
    if self.interpretation_table is not None:
      ame_data = self.interpretation_table.dropna(subset=['AME (p.p.)']).copy()
      ame_data = ame_data.sort_values(by='AME (p.p.)')
      colors = [
          '#d62728' if x > 0 else '#2ca02c' for x in ame_data['AME (p.p.)']
      ]
      ax3.barh(
          ame_data.index,
          ame_data['AME (p.p.)'],
          color=colors,
          alpha=0.85,
          edgecolor='black',
          lw=0.5,
      )
      ax3.axvline(0, color='black', lw=0.8)
      ax3.set_title(
          '3. Alavancas: Efeitos Marginais Medios (AME)',
          fontsize=12,
          fontweight='bold',
      )
      ax3.set_xlabel('Variacao Media na Probabilidade (p.p.)')
      ax3.grid(True, alpha=0.3)

    # 4. Calibration Curve
    ax4 = axes[1, 1]
    prob_true, prob_pred = calibration_curve(
        y_true, y_pred_prob, n_bins=10, strategy='quantile'
    )
    ax4.plot(
        prob_pred,
        prob_true,
        marker='s',
        color='#9467bd',
        lw=2,
        label='Calibracao Real (MLE)',
    )
    ax4.plot(
        [0, 1],
        [0, 1],
        linestyle='--',
        color='gray',
        lw=1.5,
        label='Calibracao Perfeita (45°)',
    )
    ax4.set_title(
        '4. Estimar: Curva de Confiabilidade / Calibracao',
        fontsize=12,
        fontweight='bold',
    )
    ax4.set_xlabel('Probabilidade Media Predita')
    ax4.set_ylabel('Frequencia Observada de Churn')
    ax4.grid(True, alpha=0.3)
    ax4.legend(loc='upper left', fontsize=9)

    plt.suptitle(
        'DASHBOARD EXECUTIVO: AUDITORIA LOGISTICA E DECISAO COMERCIAL',
        fontsize=14,
        fontweight='bold',
        y=0.98,
    )

    if save_path:
      plt.savefig(save_path, dpi=300, bbox_inches='tight')
      print(f'Dashboard salvo com sucesso em: {save_path}')
    plt.show()
